视频教程 · LUT

一、导入 LUT

LUT 文件是 .cube 格式，需要放进达芬奇指定的 LUT 目录，或通过项目设置导入。以下两种方式任选其一。

方式 A：放入 LUT 文件夹（推荐）

把解压出来的 .cube 文件复制到以下目录：

Windows C:\ProgramData\Blackmagic Design\DaVinci Resolve\Support\LUT
macOS /Library/Application Support/Blackmagic Design/DaVinci Resolve/LUT

放好后重启达芬奇，或在项目设置里点一下 Refresh。

方式 B：通过 Open LUT Folder 定位

  1. 打开项目设置在达芬奇里进入 项目设置 → Color Management。
  2. 点击 Open LUT Folder系统会自动打开当前项目对应的 LUT 目录，不用手动翻隐藏文件夹。
  3. 拖入 .cube 文件把 LUT 文件拖进这个目录。
  4. 点击 Refresh回到项目设置，点击 Refresh，达芬奇会重新扫描 LUT 列表。

二、在调色页使用 LUT

方式 A：直接套用到片段

  1. 进入 Color 页面打开达芬奇的 Color 页面，选中时间线上要调色的片段。
  2. 右键片段 → LUT在缩略图或节点上右键，找到 LUT 菜单。
  3. 选择对应 LUT在列表中找到你导入的 LUT 名称，点击即可套用。

方式 B：拖到节点上

在 Color 页面的 LUT 列表里，直接把 LUT 拖到节点编辑器的某个节点上，会生成一个 LUT 节点，方便后续继续调整。

方式 C：项目设置里的 3D LUT

如果希望整个项目统一套用某个 LUT，可以在 项目设置 → Color Management → 3D LUT 里指定，适合监视器校准或统一风格输出。

三、使用注意

LUT 不是万能的。 LUT 只是色彩映射，它假定输入画面处在某个色彩空间。如果素材是 Log、HLG 或 RAW，先在 Color Management 里设置正确的输入色彩空间，再套 LUT，否则会偏色或过曝。
先调曝光，再套 LUT。 建议在套 LUT 前先做基础曝光和白平衡校正，LUT 放在节点链的后段，效果更稳定。
可以调强度。 套上 LUT 后，用节点的 Key Output Gain 或 Opacity 控制强度，避免风格过重。

四、常见问题

LUT 列表里找不到？ 确认文件是 .cube 格式，且放进了正确的 LUT 目录。放完后必须点 Refresh 或重启达芬奇。
画面偏色严重？ 检查输入色彩空间是否匹配。Log 素材直接套 Rec.709 LUT 会发灰或过曝，需要先转换色彩空间。
Mac 找不到 LUT 文件夹？ 用“Open LUT Folder”最省事，不需要手动翻系统隐藏目录。
LUT 和 PowerGrade 有什么区别？ LUT 是色彩映射文件（.cube），PowerGrade 是调色节点预设（.drx），两者安装位置和使用方式不同，不要混用。

第 1 章：五分钟快速上手

步骤 1｜套用 PowerGrade

  1. 打开 PowerGrade 面板，把 Grade 拖到片段上。
  2. 立即对比 before / after，确认 CST 节点（08）的输入色彩空间与你素材匹配。S-Log2 就选 S-Gamut / S-Log2，不匹配会偏色。

步骤 2｜校正白平衡

  1. 到 WB 节点（03），用拾色器点画面中“应该是中性灰”的区域（本例中金属杆、墙面）。
  2. 注意：只动 Temp / Tint，不要动 Lift / Gamma / Gain。

步骤 3｜框选主体

  1. 到 Shape 1（05），用圆形窗口罩住主体（羊 / 人物 / 产品）。
  2. 到 Shape 2（06），框选背景或补光区。
  3. 打开 tracker 跟踪，窗口会自动跟住运动主体。

步骤 4｜微调风格强度

  1. CyanLook（09）：整体风格浓 / 淡在这里调，建议 50%–80%。
  2. Glow（20）：辉光，夜景 / 灯光镜头可开到 30+，白天建议 15 以内。
  3. 35mm（21）：颗粒，网络发布建议 20–30，大银幕可 40+。
