视频教程

安装步骤

  1. 下载并解压 点击页面底部“下载 .zip”，解压后得到 5 个 .setting 文件与一份安装说明。
  2. 找到预设目录 Windows：按住 Win + R 输入 %AppData%；
    Mac：访达中按 Command + Shift + G 输入 ~/Library/Application Support。
  3. 放入 Templates 目录 按路径进入：
    Blackmagic Design → DaVinci Resolve → Support → Fusion → Templates → Edit → Titles
    把 .setting 文件拖进去。
  4. 重启达芬奇 关闭并重新打开 DaVinci Resolve，让预设被加载。
  5. 在剪辑页使用 打开 Edit 页面 → 效果库 → Toolbox → Titles → Fusion Titles，找到对应预设，拖到时间线即可。

常见问题

看不到预设？ 确认文件放在了 Titles 文件夹里，不是 Effects 或 Transitions。放错分类不会显示。
拖到时间线没反应？ 先检查达芬奇版本，建议 18 以上。老版本可能不兼容新版 Fusion 节点。
Mac 找不到资源库？ 访达默认隐藏，按 Command + Shift + G 直接输入路径最快。
